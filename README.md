# Crysalis data and code

This repository provides candidate labels, data splits, crystal structures, DFT inputs and results, assembly trajectories, model checkpoints, and reproducibility code for *Wyckoff coordinate choice shapes initial forces in crystal assembly*.

Download [Crysalis_Data_and_Code.zip](https://github.com/Leoluis0705/Crysalis-Data-and-Code/raw/refs/heads/main/Crysalis_Data_and_Code.zip) and extract it to access the data and code. The accompanying SHA256SUMS.txt records the archive checksum. See the README inside the archive for the directory layout and instructions.
